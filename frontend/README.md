# In backend

to add dependecies you can use following command

1) to initialize the UV

uv init .

2) to add dependencies 

uv add clerk-backend-api, fastapi


3) to run the backend code

uv run server.py 


# Frontend

1) to set the frontend using vite 

npm create vite@latest frontend -- --template react

2) install dependices

npm install react-router-dom@6 @clerk/clerk-react

3) Run the frontend using

npm run dev
